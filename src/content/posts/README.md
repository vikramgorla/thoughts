# Posts

Put each post in one Markdown file:

- `professional/` for the Professional section
- `personal/` for the Personal section

The file name becomes the address of the post. For example,
`professional/working-with-legacy-systems.md` is published at
`/professional/working-with-legacy-systems/`.

Use lowercase letters, digits and hyphens in file names.

See the README at the root of the repository for the frontmatter fields.
