**Hi Guys...**   
  
Many of you would have faced problems connecting to internet using **Windows Mobile** with **Airtel Online** settings and landed in paying high for **Mobile Office**!!!!!  
  
Even i paid for **Mobile Office** for almost 6 months and then realized that i can try playing with settings... Atlast found out the settings!!!  
  
***Hope this will be useful...***  
  
Follow the below steps to configure:  
  
Go to **Settings** -> **Connections** on your windows mobile.  
Select **GPRS**, Remove all seetings which are already configured.  
Select **New** ->  
**Description** : Enter Any Name in Description., Like Airtel Online.  
**Connects** **to** : Select Work  
**Accesspoint** : airtelwap.com  
  
"Dont Change Any other settings"  
Click **Done**.  
  
Now, Come back to **connections** and select "**Proxy**"  
  
Delete all existing Proxies  
  
Select New  
**Description** : Enter any name  
**Connects** **from** : Work  
**Connects** **to** : Internet  
**Proxy(name:port)** : 100.1.200.99:8080  
**Type** : HTTP  
"Dont change any other settings"  
  
Click **Done**.  
  
Now, Open **Internet Explorer** in Mobile  
Select **Menu** -> **Tools** -> **Options**  
  
Select **Connections**  
Check **automatically detect settings**Select network : **The Internet**  
  
Click **Done**.  
  
Now, Airtel Online is configured to connect to internet on your Windows Mobile.....
