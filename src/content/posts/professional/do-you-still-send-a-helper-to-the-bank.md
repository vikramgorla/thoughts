I could pay a helper to go to the bank every month and pay my internet bill.
He does it well. But I pay him every time, and some months he does it a bit differently.
Or I set up a standing order once, and the bill gets paid every month by itself.

AI works the same way.

Many teams now let an agent do the same task every day. Read the file, check it, update the system. Every run, again.

It works. But I see three problems:

→ It is not predictable.
An agent can solve a task on one try and fail it on the next. In one benchmark, agents solved about 61% of tasks on a single try, but under 25% when the same task had to work 8 times in a row.

→ Every run costs time and tokens.
Most of it goes into reading the same instructions again.

→ A script does not get tired.
It gives the same result every time, and costs almost nothing to run.

So I prefer **agents that build automations**, not agents that are the automation. Let the agent write the script, the workflow or the pipeline once. Then let the agent repair it when it breaks.

Agents still make sense for messy inputs and real judgement calls. But only for that step.

**If you can write the steps down, let the agent write them down once.**

Which daily task would you turn into a standing order?
